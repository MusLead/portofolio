Binary Tree App

General Project:
An algorithms and data-structures project implementing several binary-tree variants in Java. A common abstract BinaryTree architecture separates shared operations from tree-specific behaviour, while AVL and Red-Black Trees implement their respective balancing mechanisms. Particular emphasis was placed on iterative rather than recursive implementations and automated testing.

Visualisation Project
An educational visualisation tool that connects binary-tree algorithms with an interactive graphical representation. Users can observe changes to the tree, follow individual node modifications and review the history of operations. The application integrates the BinaryTreeHSF implementations with JavaFX, Graphviz and WebView-based visualisation.

Term Paper: Railway Communication Security

A research project examining how safety-critical communication between trains and railway control infrastructure is protected against cyber threats. The work analyses European railway technologies including ETCS, GSM-R and FRMCS and compares their security approaches with Japanese railway systems. Topics include authentication, integrity, availability, MILS, intrusion detection and Moving Target Defence.

The repository also documents the evolution of the paper through several revisions and contains its LaTeX and Markdown source and build environment.

Simple Message Broker

A networking project implementing a lightweight publish/subscribe protocol directly on top of UDP. The system consists of a broker, publishers and subscribers communicating through a custom text protocol. It supports hierarchical topics, wildcard subscriptions, dynamic subscriber management, unsubscribe handling and both periodic and interactive publishers.

Rakaat Counter

An embedded-system prototype designed to automatically count rakaat during prayer. The system detects sujud using either an ultrasonic distance sensor or an infrared sensor. State-change and debounce logic filter sensor readings to avoid false or repeated detections. After two detected sujud movements, the system increments the rakaat count and displays the result on an OLED screen with visual feedback.

MiniShell

An operating-systems project implementing a small interactive Unix shell from scratch. The shell executes system commands through fork() and execvp(), resolves programs through PATH, supports command arguments, multiple commands and pipelines, and implements built-in commands such as cd, exit and ret. It also handles Unix signals including SIGINT and SIGHUP and includes automated functionality tests.
